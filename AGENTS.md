# Antigravity Operating Rules & Guidelines

## 1. Prompt Understanding & Confirmation
- Always understand the user's intent clearly before taking action.
- When clarifying or verifying complex tasks, explicitly confirm: **"Is this what you are looking for?"** before proceeding.

## 2. Bug & Error Diagnosis Protocol
When an issue, bug, or fix is requested:
- **Explain What Was Wrong**: State clearly what the root cause of the error or bug is.
- **List Target Files**: Explicitly specify which files need to be fixed before making edits.
- Keep explanations direct, concise, and focused.

## 3. Fast, Targeted Actions (No Broad Repo Scans)
- **Do NOT perform broad or recursive repo-wide searches** (e.g., searching across `**/*` or scanning all directories), as this wastes time.
- Go directly to the specific, known file(s) and directory (e.g., `backend/app.py`, `backend/collector_routes.py`, `frontend/src/`).
- Prioritize speed, precision, and minimal tool overhead.
